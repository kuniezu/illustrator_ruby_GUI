# Phase 1C 実機手順：単語単位のグループルビ

## 目的

横書きの親文字 `徳川斉昭` 全体に、読み `とくがわなりあき` を1個のTextFrameとして配置し、親文字範囲と同幅の両端ぞろえになることを確認する。

## 手順

1. 新規AIファイルに横書きの本文 `徳川斉昭` を1つのTextFrameとして作成する。
2. `Illustrator Ruby GUI.jsx` を実行する。
3. 4文字を連続して選択し、「グループ化」を押す。
4. ルビ入力に `とくがわなりあき` を入力して確定する。
5. 実行後、ルビが4個のTextFrameではなく1個のTextFrameであることを確認する。
6. ルビの左端・右端がおおむね親文字の左端・右端に揃っていることを確認する。
7. 本文＋ルビを `rubyPair_<frameId>` ラッパーごと移動し、相対位置が崩れないことを確認する。
8. 保存、閉じる、再オープン、再実行を行い、`baseText`、`reading`、`start`、前後context、`grouping=group` が復元されることを確認する。
9. 1文字単位のルビも従来どおり生成できることを確認する。

## 合格条件

- `徳川斉昭` に対して `とくがわなりあき` が1個のルビTextFrameとして生成される。
- ルビの左右端が親文字範囲に揃い、単純な中央配置や1文字ごとの個別ルビになっていない。
- Phase 1B のラッパー構造と両立する。
- 保存・再オープン後にグループルビのメタデータを読み込める。
- 既存の個別ルビ生成が壊れていない。
