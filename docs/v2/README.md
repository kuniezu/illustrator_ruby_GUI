# Illustrator Ruby GUI v2 — 設計検討ワークスペース

更新日: 2026-09-05
状態: Draft 0.1

このディレクトリは、現行 `Illustrator Ruby GUI.jsx` をそのまま拡張することを前提にせず、展示パネル・教材・博物館解説文などの長文で使える「再編集可能なルビ管理ツール」を再設計するための資料置き場です。

## 文書の役割

- `spec/`: ユーザーとSolの対話で合意した要求仕様。設計分析より優先する。AI分析側は勝手に変更しない。
- `findings/`: 現行コード、Issue、PR、Illustrator実機検証から得た観測事実。要求や設計案とは分離する。
- `analysis/sol/`: Solによる独立した設計分析・仮説。要求仕様そのものではない。
- `analysis/atlas/`: Atlasによる独立分析の配置先。Sol分析の追認を目的としない。
- `prompts/`: 他モデルへ分析を依頼するときの引継ぎ文書。
- `decisions/`: Sol/Atlas等の分析を比較した後、人間が採用した設計判断をADR等で残す将来配置先。

## 進め方

1. `spec/` を要求の正本候補として固定する。
2. `findings/` を実機事実として固定する。
3. SolとAtlasが同じ資料・現行コードを独立に分析する。
4. 一致点、相違点、一方だけが指摘したリスクを比較する。
5. ユーザー判断を経て `decisions/` と target architecture を確定する。
6. その後に初めてv2実装へ進む。

この段階ではPR #8を完成させること、現行GUIを維持すること、wrapper方式を採用すること、新機能を実装することを目的にしません。

## 公開リポジトリ上の注意

実展示原稿、内部資料、実運用辞書、個人名等の案件固有データは置きません。例示は `日本庭園`、`一張羅` など一般的な語を使用します。
