# 実装・実機前チェックリスト

この文書は、過去に実際に発生した見落としを再発させないための共有チェックリスト。

- Luna/Codex/Work worker: **実装開始前** と **完了報告前** に確認する。
- ChatGPT supervisor: **remote review時** と **ユーザー実機を依頼する直前** に確認する。
- ユーザー: 必要に応じて内容を確認できるが、チェック作業の責任をユーザーへ移さない。

チェックリストは `known-failure-regression-catalog.md` の代替ではない。catalogはコード不具合の回帰、こちらは実装・レビュー・運用上の見落とし防止を目的とする。
